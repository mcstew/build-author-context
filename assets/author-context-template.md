## Context Router

Before performing a task:

1. Read Agent Protocol, protected global boundaries, and Current Operating State.
2. Identify the relevant project, series, and pen name.
3. Apply context from Author -> Pen Name -> Series -> Project.
4. Let lower-tier explicit overrides win unless they weaken a protected global boundary.
5. Consult source-of-truth files when stakes are high or summaries are insufficient.
6. Check approvals and open confirmations.
